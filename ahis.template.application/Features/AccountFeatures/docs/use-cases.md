# Account Use Cases

- Register an account and send confirmation email.
- Confirm email using a Base64Url-encoded Identity token.
- Set the first password for a known user without a password.
- Update the authenticated user's profile and mark configuration complete.
- Generate a fresh authenticator key and provisioning URI.
- Verify an authenticator code, enable 2FA, and return recovery codes.
- Disable the authenticated user's authenticator.
- Change the authenticated user's password and invalidate sessions.
- Resend confirmation email.
- Return the authenticated user's account details.
